# 世志賽車

以使用者提供的糖果賽車為基礎，獨立使用 Rapier／Three.js、原18位共用角色及64個原版／造型選項。選車的六個選項是原車體的車色及能力組合，不是六種幾何車款。賽車存檔使用 `wvs.racing.save`；不啟動大亂鬥或排球的程式。

## 流程與三張地圖

單人：角色 → 造型 → 車輛 → 地圖 → 比賽。

連線：開房／加入 → 每人選角色、造型、車輛並準備 → 房主選圖 → 全員載入後起跑。換圖會替換完整世界並保留選好的車色與造型。房間內不能由客端自行換圖。

- 臺大・總圖男八巡遊：約1053遊戲公尺。大門→椰林大道→總圖→長興街男八→南側回程→大門。是縮放及部分連接道路調整的路線試作，不是實測導航地圖。校門、總圖拱窗與側塔、男八、傅鐘、腳踏車架及椰樹列為自製地景。無原體育館跳台。
- 糖果山谷：約820公尺。保留原路線、捷徑、跳台與地景。
- 恐龍・失落火山谷：約888公尺。原創長頸龍、化石拱門、恐龍蛋、叢林、火山和跳台。恐龍及熔岩目前屬路外地景，沒有未提示的傷害判定。

`src/maps/catalog.ts` 管理地圖；`setActiveMap` 與 main 的 `switchWorld` 切換完整場景、物理、道具箱、AI 和小地圖，並釋放舊世界資源。沒有遊戲內編輯器。原始碼製圖說明在 `public/map-guide.html`。

## 角色技能與資產

`src/custom/sharedCharacters.ts` 編譯時唯讀匯入`shared/characters/*.js` 的獨立角色快照，在獨立作用域建立角色與模型。只呼叫技能的模型工廠，不執行原遊戲戰鬥回呼。`ITEM_SKILL_SOURCES` 記錄23種道具的原角色檔案和 moves/fire 出處。

直接沿用原鬆餅、筊杯、奶龍與貝殼模型；追蹤學生使用原人物的小型模型；芭樂沿用既有工廠。Reels手機與炸彈以獨立低面數幾何製作。效果依賽車規則改編：所有車手均可從道具箱取得，沒有角色專屬能力或大亂鬥傷害數值。三連道具目前逐次使用，尚無環繞防禦；部分狀態道具仍以光圈／HUD呈現。

完整對照在 `public/items-guide.html`；來源、地圖限制與研究在 `public/design-plan.html`。不提取任天堂模型／貼圖／音效，沒有啟用Google付費API。

## 連線與手機

PeerJS 1.5.4：可靠通道傳房間／準備／結果，非排序通道傳30Hz操作及15Hz Float32狀態。v4協定與地圖簽章避免未知版本錯配；已知地圖可在同一房間直接同步切換。無畫面、聲音或程式碼串流。房主統一判定物理、道具、AI和圈數；客端使用110ms主機時間補間、限量外推及自身平滑修正，沒有完整物理回滾。

手機預設低畫質，限制像素比和陰影，持續低幀率會再降低解析度。線上暫停只停止自己的輸入，整場繼續；斷線者由AI接手，房主離開時退出該場。沒有房主遷移或自有TURN；嚴格NAT仍可能無法直連。瀏覽器模擬測試不取代實際手機／跨網路測試。

## 開發與驗證

`npm ci`、`npm run dev`；`npm run typecheck`、`npm test`、`npm run build`。一般dist以靜態伺服器開啟。`npx vite build --config vite.standalone.config.ts` 產生單一IIFE及內嵌CSS，再將字型和JS內嵌到HTML供試玩。單人程式可離線，連線需要網路。新增中文後以有Noto字型和fontTools的環境執行 `python3 scripts/subset-fonts.py`。

本版53項單元測試；三圖各六台AI完成三圈；瀏覽器驗證角色→車→地圖流程、切換世界與原技能模型；雙客戶端測試房主選圖、保留造型與車色、道具、結果、再開及斷線，含模擬延遲和掉包。

## 隔離與靜態試玩

所有賽車程式與依賴都位於 `racing/`。`shared/characters/` 是原角色的獨立快照；`shared/vendor/` 放置 PeerJS 與授權。賽車不再直接讀取 repo 根目錄的 characters 或 js，因此修改賽車副本不會影響其他遊戲。原角色變更不會自動同步，需明確更新賽車副本後驗證。

GitHub Pages 由根目錄 `racing.html` 轉到 `racing/play/`。`play/` 是本次原始碼建置的靜態成品，不載入排球、大亂鬥或土木的 runtime。修改原始碼後執行 `npm run build -- --outDir play` 更新成品，再提交來源與成品。`npm ci`、`npm test` 可在本資料夾獨立執行。

手機預設左右方向鍵及自動加速，右側漂移與道具；設定可切換滑桿、調整大小和透明度。53項單元測試通過，新手機配置仍需實機與跨網路驗證。
