# 世志遊戲俱樂部

固定開啟大廳連結：https://balala-bubu.github.io/wvs23fight/
首頁可選「世志大亂鬥」、「世志排球」或「阿Wa隆」。排球為獨立試玩模式，支援單人、雙人合作／對戰、四人分割與手機動作／觸控手把；完整流程與操作見 [排球模式規劃](docs/volleyball-mode.md)。三個模式分開載入。

## 世志大亂鬥

PS2 風格的 3D 平台格鬥遊戲，2～4 人，可以用手機當手把。

## 阿Wa隆

5～10 人的 3D 隱藏身分派對遊戲，從首頁或 `avalon.html` 進入。支援你與電腦的練習場，以及 PeerJS 資料同步的多人模式；各裝置自行繪圖，不分享螢幕。

- 同地模式：開房裝置當大螢幕，每位玩家用自己的手機輸入四位房號或掃 QR Code 加入。
- 遠端模式：每位玩家在自己的裝置看完整畫面並操作。開房裝置同樣不占玩家名額。
- 有真人加入後，房主可另選上帝主持，選擇系統語音或自己唸情境逐字稿；上帝不參加任務。系統語音在同地模式只從開房裝置播放，遠端模式則每位玩家的裝置各自播放公開播報；自己唸模式不啟用系統語音。私人角色、同夥與仙女查驗資訊只送給對應玩家。
- 角色設定支援照片臉、左右拖曳旋轉、選用手機轉動，以及照片單指移動／雙指縮放。
- 可用電腦補空位。現版遊戲中斷線會停止當局，尚未支援重連續局或房主轉移；真機跨網路的 WebRTC 連通與感測器手感仍需實測。
- 保留此版自訂規則與角色配置；派西維爾與莫甘娜目前固定加入，尚無角色選配介面。

## 怎麼玩
- **自己玩**：對電腦，或兩個人用同一個鍵盤
- **連線**：一台電腦或平板「開房」當大螢幕，朋友用手機打開同一個網址 →「連線 → 加入」，輸入房號，手機就變成手把

手機和大螢幕是直接連線（透過 PeerJS 免費配對服務），不用登入。少數公司或學校網路會擋直接連線，遇到時改用手機熱點就好。

## 操作
- P1：`A` `D` 移動、`W` 跳、`S` 下、`J` 攻擊、`K` 必殺、`L` 防禦、`U` 大招
- P2：方向鍵、`,` 攻擊、`.` 必殺、`/` 防禦、`Enter` 大招
- 手機：左半邊拖曳＝搖桿，右邊按鈕

## 檔案結構
- `brawl.html`：大亂鬥畫面和樣式，最下面列出要載入的角色和地圖
- `js/core.js`：遊戲本體（物理、操作、選角、連線、結算）
- `characters/`：一個角色一個檔案（外型、招式、大招、勝敗動畫都在裡面）
- `maps/`：一張地圖一個檔案
- `characters/_template.js`、`maps/_template.js`：新增時的範本
- `tools/smoke_test.py`：自動測試，跑過每個角色的招式、大招和勝敗動畫

新增角色：在 `characters/` 放一個新檔案，再到 `brawl.html` 最下面加一行 `<script src="characters/新代號.js"></script>`。地圖同理。


## 開發與試玩

在專案根目錄執行 `python3 -m http.server 8000`，瀏覽 `http://localhost:8000`。

排球瀏覽器測試：`python3 tools/volleyball_test.py`（需要 Playwright 與 Chromium）。
原大亂鬥測試：`python3 tools/smoke_test.py --only=tommy`。

排球物理／感測器測試：`node tools/volleyball_rules_test.cjs`。
手機協定測試：`python3 tools/volleyball_phone_test.py --mock-transport`（使用測試通道，不代表實機 WebRTC 或感測手感已驗證）。
阿Wa隆播報分流測試：`python3 tools/avalon_narration_test.py`（模擬資料通道與語音 API，驗證遠端／同地／手動主持、重複訊息及私密資訊不朗讀）。

## 震動
- 右上角「震動：開／關」可隨時切換；手機手把也有相同開關，會記住這台裝置的選擇。
- 支援 Vibration API 的裝置（例如 Android Chrome）會在按操作鍵、受擊與出局時震動；手機手把另有大招集滿提醒。
- 關閉震動會立即停止回饋；切換分頁、暫停或離開時也會停止。震動與音樂開關互相獨立。
- iPhone／iPad Safari 不支援網頁 Vibration API，不會顯示震動開關（按鈕自動隱藏）；遊戲仍可正常操作。實際震動也受裝置與系統設定影響。
