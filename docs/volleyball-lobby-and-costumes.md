# 世志排球：大廳、角色與造型選擇

## 目標與範圍

延續世志大亂鬥的大廳操作：完成設定後進入 3D 角色預覽，先選角色，再選該角色原有造型，最後開賽。重用角色與造型定義，不修改 `js/core.js`、`characters/`、地圖或音效。單人與多人使用同一個選角大廳。

## 進入流程

- 單人：一個人玩 → 玩法設定 → 選角色 → 決定角色 → 選造型 → 決定造型 → 開賽。
- 同地多人：跟朋友玩 → 在同一個地方 → 人數／隊伍設定 → 選角大廳自動建立房間 → 手機掃 QR Code 或輸入房號加入。
- 遠端多人：跟朋友玩 → 各自在家 → 設定 → 同一個選角大廳；P1 保留給主機，朋友在手機收看主機畫面並操作自己的角色。
- 返回設定不關閉房間；房號、QR Code、連線／準備狀態留在選角大廳上方。可用「房間設定／加入」打開完整房間面板；連線失敗可重試。

## 選角與造型

四張玩家名牌、18 個原角色頭像與場邊 3D 預覽。點名牌可替該位置選角。角色確認後顯示其原有造型，點造型立即更換預覽；「返回角色」取消造型步驟。沒有額外造型的角色可直接確認。AI 角色可由主機選擇。

造型索引從 0 開始；0 為原版，其餘依 `CHARS[kind].skins`。使用既有 `skinCount`、`skinName` 與 `makeModel(kind, skin)`，開賽仍保留已選造型。模型快取包含角色、造型及玩家位置，避免更換一位玩家時連帶影響其他人。

## 手機加入後

手機收到主機的輕量角色目錄，不載入 Three.js 或角色建模程式。選角時顯示角色、造型及確認按鈕，送出選擇後由主機更新大廳預覽與名牌。選好後再選動作／觸控手把並準備，主機負責開賽。收到開賽狀態後隱藏選角面板。

## 連線訊息

- `roster`：主機首次指派手機時發送角色代碼、名字、頭像與造型名稱。
- `selection`：手機傳送 `character`、`skin`、`confirm` 或 `back`；主機以已指派的連線位置作為操作對象，不接受手機自行指定其他玩家。
- `state.lobby`：包含大廳步驟、四位角色的角色代碼、造型索引、選擇階段與確認狀態。
- 非選角期間忽略選角操作；驗證角色代碼、造型範圍並限制訊息頻率。

## 修改位置

- `volleyball.html`：大廳房間面板、造型列、手機選角面板。
- `js/volleyball.js`：本地選角／造型狀態、模型預覽、手機選擇處理。
- `js/volleyball-network.js`：房間資訊同步、手機目錄及選角協議。
- `css/volleyball.css`：大廳房號／QR Code 與造型、手機選角版面。

## 快速驗收

1. 單人確定角色後出現該角色的造型，換裝能在 3D 預覽與正式比賽保留。
2. 同地多人設定完成會進入選角大廳，同時出現房號與 QR Code。
3. 手機加入後能選自己的角色與造型，主機同步顯示；不能更改別人的位置。
4. 返回角色／設定後再進入，房間和已選造型仍可使用。
5. 真實 Safari 觸控及跨網路 WebRTC 媒體品質仍需實機確認。

## 球場容錯調整

球場長寬各增加 10%，由 14 × 28 調整為 15.4 × 30.8；保持 1:2 比例。球場配色、邊線、球網與出界判定共用尺寸，鏡頭取景及橫向移動邊界同步調整。

單人與多人入口皆可選單人挑戰（1 真人、3 AI）；多人另有雙人同隊（對戰兩位 AI）、雙人分隊（各搭一位 AI）與四人對戰，全數固定二打二。單人手機手把可從「在同一個地方」建立房間加入。「模式首頁」僅顯示於排球最初主畫面。

直向手機手把：動作按鈕在上方，下方只有一個大搖桿；搖桿固定在可視區底部中央，避開安全區，上方內容預留空間可捲動。

導航：各設定／朋友／選角頁的上方有「排球首頁」可直接返回；最外層「模式首頁」仍只顯示於最初主畫面。「跟朋友玩」的「加入房間」為獨立大按鈕，開啟獨立房號輸入面板；房間設定則顯示完整開房面板。

## 殺球、好球連段、手勢與隨機（2026-10-23）

- 真人殺球命中窗口放寬至目標時機前後 0.55 秒，水平可及距離 3.4，高度容錯 3.0，仍需起跳。時機越準球越快；大幅失準球較慢且拋物線較高，偏斜懲罰縮小。
- 品質：失誤淡紫／普通白／NICE 綠／GOOD 黃／SUPER 亮紫，球本體與球尾跡同步染色，品質文字跟隨球顯示在球上方。接球 NICE 開始累積，後續好的舉球、殺球接續提升，時機不佳最多降低一階；攔網不增加累積。
- 球後方新增有寬度且逐漸收細的尾跡，依擊球品質同步變色；低面數、沿用固定 BufferGeometry。
- 攔網通常向可救範圍緩衝；僅強攻擦到極外緣、具足夠橫向速度時形成 block-out，最後觸球失分規則保留。
- 手機放平向上揮可接球／起跳；舉球採手機舉高、背面朝上往上推；再向下揮殺球。重力估計隨握姿更新，避免只支援校正時的單一握法。左右下揮方向傳送有限幅 `aim` 值，不傳原始感測資料。中央揮動設死區。
- 接球／攔網降低橫移與傾斜靈敏度；距離接球點 1.3 內、剩餘 0.65 秒且未明顯推搖桿時，平滑輔助定位，不瞬移、不自動擊球。
- 選角頭像列有「？」；點選即抽定角色及造型並確認，不再進入造型頁。手機同樣提供隨機選項。
- 已以模擬感測資料驗證放平／背面朝上姿勢及上下、方向判斷；實際 iPhone／Android 手感仍需實機試玩。
