# 排球 v3：影片參考與比例迭代

## 來源與證據範圍

使用 Higgsfield 的 YouTube 分段分析工具處理以下公開影片，並對照任天堂官方玩法指南。這是影片分析結果，不是人工逐格觀看或像素量測；分析文字可能有錯誤，不能從中推導原版鏡頭焦距、場地尺寸或精確毫秒數。原始分析保留於本機 `work/reference/video-analysis.json`（不部署）。

- [SWITCH SPORTS 4 PLAYERS! Volleyball Gameplay in Split-Screen Multiplayer](https://www.youtube.com/watch?v=aWh_9vr4hW4)：分析指出 2:02–2:34 進入四分割實戰，2:34–3:21 有起跳、扣球與攔網。用於檢查多人各自視角和分開起跳／擊球的流程。
- [Nintendo Switch Sports Gameplay: Volleyball](https://www.youtube.com/watch?v=HhNBqUgOCNY)：分析指出 1:22–2:19 是接球與托球教學、2:19–3:16 是上揮起跳／下揮扣球、3:16–3:53 是攔網、4:09–6:24 是正式比賽。分析可支持動作次序與時機教學方向，不能精確量測每次球飛行秒數。
- [Nintendo Beginner Basics](https://www.nintendo.com/jp/ichikara/as8sa/03_en.html)：交叉確認接托扣的 Nice 連鎖、強攻球、快攻、背飛和封鎖球路。此版本仍未完整實作背飛、封網出界、逐動作循序教學及重播。

## 此次實際修改（本作自行調校，非原版測量值）

| 項目 | v2 | v3 |
| --- | --- | --- |
| 有效場地寬 × 長 | 14 × 23 | 14 × 28，半場接近方形 |
| 後排接球深度 | 約 8 | 約 9.8，發球線前位置約 13.4 |
| 網前攻擊位置 | 約 1.7 | 約 2.1 |
| 球場界線與判定 | 個別數字 | 共用 `VOLLEY_COURT` 的長度與球半徑，遠底線實測內外球 |
| 網前攝影機 | 固定距離 9，跟角色貼近球網 | 距離 12.5–14，網前稍升高，肩側偏移讓球路避開背影 |
| 分割／直式構圖 | 只加廣角 | 依視窗寬高調整距離，最遠 18；移開後牆與吊旗，排除貼近鏡頭的隊友遮擋 |
| 球尾跡 | 固定 12 幀 | 約 0.20 秒的時間取樣，30/60 Hz 不會變成不同長度 |
| 落地高度 | 球心 0.34 | 球場表面 0.15 + 球半徑 0.36 |
| 揮空回饋 | 過早提示較籠統，過晚不提示 | 顯示過早／晚了一點，保留實際接觸判斷 |

球的每段飛行仍由重力、起終點與時間求初速，再以固定小步長積分；角色跑位與球的落點都一併更新，沒有單獨把地板拉長。接、托、扣的既有節奏先保留，避免在沒有逐格量測的情況下臆造原版時間。

## 驗證與待真人試玩

- 規則測試：CPU 正常來回、起跳、接托扣、球網、攔網、比分、暫停、遠底線內外球和感測器合成輸入。
- 瀏覽器測試：18 個角色、鍵盤實際接球→AI 托球→真人起跳扣球、跟隨鏡頭、雙人合作／對戰、四分割、手機橫直式版面。
- 手機真實感測器手感、跨裝置 WebRTC 延遲仍需實機試玩；本輪沒有取得新的實機驗證。
