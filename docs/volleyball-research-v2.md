## 原型錯在哪裡

| v1 問題 | v2 設計 |
| --- | --- |
| 高處固定全場鏡頭，角色太小 | 每個玩家有角色後方的跟隨攝影機，跟著跑位與球調整目標 |
| 兩人共看同一畫面 | 雙人左右分割，四人四宮格；每格有自己的角色身份與下一個動作提示 |
| 一人交替操作整隊 | 每個真人固定一個角色；單人隊友由 AI 托球／防守，雙人可選合作或對戰 |
| 讀底部進度條，角色不重要 | 看球靠近身體、托球高度與起跳時機，提示直接出現在角色視角裡 |
| 只有按扣球，沒有主動起跳 | 起跳與擊球分開；防守也要移動攔網、選擇起跳時機 |
| AI 每次觸球隨機決定是否失誤 | 用反應延遲、移動速度、實際距離、站位與球速判斷能否接到 |
| 得分由計時狀態直接決定 | 實際球飛行、球落地、球網和攔網接觸判定 |
| 淡黃沙地、霧和掃描線壓低可讀性 | 明亮室內球館、清楚的藍綠／珊瑚場地、木地板、柱樑窗戶、觀眾和陰影；移除掃描線 |

## 玩法轉譯

保留 2 對 2、接 → 托 → 扣、球不落地和得分方發球。角色固定，人類與 AI 使用同一個球／場地判定。連續 Nice 增加球的顏色與速度；三連鎖扣球的攔網結果要與普通扣球不同。

鍵盤／觸控不是 Joy-Con 體感：以「移動」「起跳」「擊球」三類操作轉譯。先完成基本發球、接托扣、攔網和雙人／四人視角；不宣稱完整還原原作所有更新招式。

## 驗收重點

1. 球從接球者手臂、托球者手上、躍起扣球者手附近出發；沒有瞬移或穿過身體。
2. 單人視角跟著固定角色；角色左右移動／前後換位時攝影機有連續變化。
3. 合作模式兩人看同一個世界的不同位置，對戰則從球網兩側各看自己方向；四人四宮格。
4. 放著不操作，真人會漏球；CPU 對普通發球與容易的球不無故漏接。難度差異來自反應、跑位、封路與攻擊選擇。
5. 普通扣球可以被合理攔回；強力扣球被碰到時會削弱／改變路線，仍可能救起。
6. 從落地與網接觸結算得分，暫停不偷偷推進比賽。
7. 使用原角色、保留原大亂鬥與按模式載入的首頁。僅更新私人試玩站，不推送 GitHub。
